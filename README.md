# designmychaos.com

Source for the Chaos Designs one-page website, hosted on GitHub Pages.

Plain HTML/CSS/JS — no build step, no framework. Edit `index.html` / `styles.css` / `script.js` directly and push to `main`; GitHub Pages redeploys automatically within a minute or two.

```
index.html      Page markup (hero, about, services, portfolio, utilities, contact)
styles.css      All styling, incl. responsive breakpoints
script.js       Mobile nav toggle + scroll-reveal animation (~40 lines, no dependencies)
assets/img/     Logo variants, favicons, app icons
CNAME           Custom domain (designmychaos.com) for GitHub Pages
```

See the repo's **Settings → Pages** for the GitHub Pages configuration, and your DNS provider for the custom-domain records pointing at GitHub.
